# 📰 FatoRapido App

App Android desenvolvido em Java para visualização de fatos aleatórios utilizando a Facts API. O projeto foi desenvolvido como trabalho acadêmico para demonstrar conceitos de desenvolvimento mobile.

---

## 🎯 Funcionalidades

  - 🔍 Gerar Fatos: Gere fatos por categória ou aleatóriamente
  - 📖 Detalhes Completos: Tela dedicada com informações detalhadas  
  - 💾 Persistência Local: SharedPreferences para salvar fatos favoritos  
  - 🌐 Consumo de API: Integração com Facts API
    
---

## 🛠️ Tecnologias Utilizadas

  - **Linguagem:** Java / Kotlin
  - **API:** Facts API (https://f-api.ir/)
  - **HTTP Client: Retrofit 2.9.0**
  - **IDE:** Android Studio  
  - **Framework:** Android SDK
